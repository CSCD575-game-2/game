# SPARTS

## Downloads

- [https://github.com/CSCD575-game-2/game/releases/tag/v1.0](https://github.com/CSCD575-game-2/game/releases/tag/v1.0)

### Windows
Download `SPARTS-Windows.zip`, extract, and run `CSCD575-Game2.exe`.

### macOS
Download `SPARTS-Mac.zip`, extract, and right-click → Open.

You may need to do this command: `xattr -dr com.apple.quarantine sparts.app`
